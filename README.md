# BILKY — Premium Luxury Fashion House

A sophisticated fashion showcase and curated luxury brand experience built with pure HTML, CSS, and JavaScript.

## Pages

- **Home** — Hero section, animated promo marquee, brand introduction, featured collection highlights
- **Product Showcase** — Curated luxury fashion items with product filters and detailed descriptions
- **Board of Trustees** — Leadership team and brand vision
- **Inquiries & Appointments** — Contact form for consultations and customer inquiries
- **Upcoming Events** — Fashion events, collections launches, and exclusive gatherings

## Project Structure

```
bilky-fashion-house/
├── index.html                 # Home page
├── styles/
│   └── styles.css            # Global styles and design system
├── pages/
│   ├── products.html         # Product showcase
│   ├── contact.html          # Inquiries & appointments
│   ├── events.html           # Upcoming events
│   └── trustees.html         # Board of trustees
└── scripts/
    ├── script.js             # Global/home functionality
    ├── products.js           # Product page features
    ├── contact.js            # Contact form handling
    └── trustees.js           # Trustees page functionality
```

## Quick Start

Simply open `index.html` in any modern web browser — no installation or build process required.

```bash
open index.html
```
